# Windows Update Multitool

A PowerShell utility for repairing and managing Windows Update on Windows 11 systems. The script includes a guided menu for blocking feature updates, resetting Windows Update components, installing offline `.msu` or `.cab` packages, and running basic system-health repairs.

## Features

- Feature Update Pauser
  - Locks or unlocks the Windows Update target version to prevent feature upgrades from being offered.
  - Can apply changes immediately or after a restart.

- Windows Update Repair
  - Stops update-related services.
  - Clears queued download files.
  - Resets `SoftwareDistribution` and `Catroot2` folders.
  - Re-registers Windows Update DLLs.
  - Resets Winsock and WinHTTP proxy settings.

- Manual Offline Updates
  - Installs downloaded Microsoft update packages from the `MSUUpdates` folder.
  - Supports `.msu` and `.cab` files.
  - Can run silently or interactively.

- System Repair
  - Runs `DISM /Online /Cleanup-Image /RestoreHealth`
  - Runs `SFC /scannow`
  - Runs `DISM /Online /Cleanup-Image /StartComponentCleanup`

- Update Utilities
  - Scans for pending and optional updates.
  - Clears the SoftwareDistribution cache.
  - Opens Windows Update settings.
  - Opens installed updates control panel.
  - Views the multitool log file.

## Requirements

- Windows 11
- PowerShell running as Administrator
- The script will prompt for elevation automatically if needed

## Files

- `WinUpdate_MultiTool.ps1` – main script
- `MSUUpdates/` – folder used for offline `.msu` and `.cab` packages
- `WinUpdate_Multitool.log` – activity log generated by the tool

## Run the script

You can run the script in either of the following ways:

### Option 1: Local script file

```powershell
Set-ExecutionPolicy Bypass -Scope Process
.\WinUpdate_MultiTool.ps1
```

### Option 2: Download and execute in memory with `irm | iex`

```powershell
irm https://raw.githubusercontent.com/<your-user>/<your-repo>/main/WinUpdateMultiTool/WinUpdate_MultiTool.ps1 | iex
```

If you are using a different GitHub repository path, replace the URL with the correct raw GitHub link.

The script automatically detects whether it is running from a file or in memory and requests administrator elevation when needed.

## Main menu options

1. Feature Update Pauser
2. Fix Windows Update (full reset and repair)
3. Manual Offline Update Installer
4. System Health Repair
5. Update Utilities
6. Exit

## Important notes

- This script makes system-level changes to Windows Update components.
- Some actions restart services or the entire PC.
- Always save work before choosing a reboot option.
- The script writes a log file to the working folder so you can review what changed.

## Safety advice

Use the repair and reset features only when you are troubleshooting failed updates, update cache corruption, or Windows Update service issues. Some options can temporarily interrupt updates or require a full reboot.

## AI Use

This script was originally designed to block updates for devices running Windows 11, version 23H2, however it has been expanded to have additional features. The following AI tools have been used:
